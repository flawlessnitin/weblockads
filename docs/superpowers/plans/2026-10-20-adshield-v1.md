# AdShield v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Manifest V3 Chrome extension that removes YouTube ads, blocks ads and trackers on all sites, and has the approved light popup, stats, remotely updatable YouTube rules, a settings page, and a nightly GitHub breakage check.

**Architecture:**
- **Network blocking:** EasyList, EasyPrivacy, uBlock and IndianList filter lists are converted at build time into committed DNR static rulesets.
- **Cosmetic filtering:** element hiding runs in the service worker using Ghostery's engine, which is serialized at build time. CSS is applied with `chrome.scripting.insertCSS`.
- **YouTube:** an isolated MAIN-world module prunes ad fields from player data. It is driven entirely by a JSON rules file that the extension re-downloads daily from the GitHub repo. A mute/fast-forward/skip fallback handles ads that still play.
- **Code vs data:** all behaviour that changes when YouTube changes is data, never code.

**Tech Stack:**
- TypeScript 7.0, esbuild 0.28, Vitest 5 (+ jsdom 30), Playwright 1.64.
- `@ghostery/adblocker` 2.20 (MPL-2.0) and `@ghostery/adblocker-webextension-cosmetics` 2.20 (MPL-2.0).
- `@ghostery/urlfilter2dnr` 2.1 (GPL-3.0, AdGuard converter).
- `tldts` 7 (MIT), `@resvg/resvg-js` 2.6 (icons, build-time only), npm.

**Spec:** `docs/superpowers/specs/2026-10-20-ad-blocker-design.md`

**Out of this plan (separate plans later):** pop-up protection (plan 2) and Hotstar (plan 3, after investigation). v1 already requests `<all_urls>`, so neither needs a permission change. The popup shows a "Pop-ups" category that stays at 0 until plan 2.

## Global Constraints

- Manifest V3, Chrome only. Host permissions `<all_urls>` from v1.
- **No remote code.** Remote fetches return JSON data only and are schema-validated. Never `eval`, `new Function`, or remote `<script>`.
- **No telemetry or analytics.** All stats live in `chrome.storage` on the device. The only network requests the extension makes are to the rules file URL.
- License GPL-3.0-only for our code. Keep attribution for EasyList, EasyPrivacy, uBlock Origin uAssets, IndianList, Ghostery and AdGuard in `THIRD_PARTY_NOTICES.md`.
- Do not fork uBlock Origin Lite or any complete extension. Libraries are used only for list→DNR conversion and cosmetic filter matching.
- **Product name:** `AdShield` is a placeholder. It must live only in `src/shared/config.ts` (`PRODUCT_NAME`) and flow from there into the manifest, popup and options.
- **Repo:** `REPO_SLUG` in `src/shared/config.ts`, read at build time from env `ADSHIELD_REPO`, default `"OWNER/adshield"`. The product owner supplies the real value before publishing (Task 15).
- **Rules file URL:** `https://raw.githubusercontent.com/${REPO_SLUG}/main/rules/rules.json`.
- **Popup:** light theme, about 320 px wide, indigo accent `#4f46e5`. Ring colours: video ads `#ef4444`, ads & trackers `#f59e0b`, pop-ups `#8b5cf6`. Layout exactly as in the approved mockup `.superpowers/brainstorm/1721-1792509289/content/popup-own-v1.html` ("Light" card).
- **YouTube surfaces in v1:** `www.youtube.com`, `youtube.com` (incl. Shorts and `/embed/`), `www.youtube-nocookie.com`. Not `music.` or `m.`.
- **Average ad length** for "ads skipped" when the real duration is unknown: `AVERAGE_AD_SECONDS = 15` *(developer's call)*.
- Commit messages: conventional style, with **no** Claude/Anthropic co-author trailer (product owner's global instruction).

## Review Focus

1. **YouTube SPA navigation** (clicking from one video to the next without a page reload) must still strip ads. Pinned by Task 8 test `prunes /youtubei/v1/player responses read via Response.json`.
2. **A broken, partial or older remote rules file** must never wipe out working rules. Keep the last good copy and never downgrade. Pinned by Task 6 tests `rejects malformed rules` and `ignores lower version`.
3. **Pruning must not remove the real video** (`streamingData`, `videoDetails`, `playabilityStatus`). Pinned by Task 7 fixture test `keeps playback fields intact`.
4. **The fallback must restore the user's own volume, mute and speed** after an ad, including when the user was already muted or at 1.5×, and must never touch a non-ad video. Pinned by Task 9 tests `restores user state` and `ignores non-ad video`.
5. **YouTube "confirm you're not a bot" pages** on GitHub's datacenter IPs must not send a false "YouTube broke" email. Pinned by Task 14 test `classifyRun returns inconclusive on bot check`.

### Task 7: YouTube pruning + live fixtures

**Files:**
- Create: `src/youtube/prune.ts`, `scripts/capture-youtube.ts`, `tests/fixtures/youtube/*.json`
- Test: `tests/unit/prune.test.ts`, `tests/unit/youtube-fixtures.test.ts`

**Interfaces:**
- Produces: `pruneByPaths(root: unknown, paths: readonly string[]): { removed: number; adBreaks: number }`.
  - Mutates `root` in place.
  - A path is anchored at the root, its segments are split on `.`, and `*` matches every own key of an object or every index of an array.
  - The final segment is removed with `delete`.
  - `removed` counts deleted properties.
  - `adBreaks` sums `array.length` of deleted values whose final key is `adPlacements`.
  - Non-objects return `{removed:0, adBreaks:0}`.
- `capture-youtube.ts [--signed-in <userDataDir>] <videoId…>` launches Chromium **without** the extension. It records the response bodies of `/youtubei/v1/player` and `/next`, plus `ytInitialPlayerResponse` and `ytInitialData` evaluated on the page. It writes `tests/fixtures/youtube/<date>-<videoId>-<kind>.json` with tokens and cookies scrubbed: it drops the keys `responseContext.serviceTrackingParams`, `trackingParams`, `clickTrackingParams` and any value matching `/SAPISID|__Secure/`.

- [ ] **Step 1: Failing unit tests** (`prune.test.ts`):
  - `{adPlacements:[1,2], videoDetails:{}}` with `["adPlacements"]` → `{removed:1, adBreaks:2}` and `videoDetails` kept.
